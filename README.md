# Bài Thi Thực Hành Giữa Kỳ - Lập Trình Web

- **Họ và tên:** Huỳnh Nhật Gia Huy
- **Môn học:** Lập trình Web (14113015)
- **Đơn vị:** Trường Đại học Gia Định - Khoa Công nghệ Thông tin

## Cấu trúc bài làm
- `index.html`: Cấu trúc HTML5 Semantic, Accessibility, Form & Table.
- `css/style.scss`: Mã nguồn SCSS (Variables, Mixin, Nesting, Flexbox & Grid, Breakpoints).
- `css/style.css`: File CSS đã được biên dịch từ SCSS.
- `js/script.js`: Xử lý DOM, Arrow Functions, Form Submit, Fetch API (async/await), LocalStorage, Try/Catch.
- `js/data.json`: Dữ liệu JSON danh sách dự án phục vụ Phần 4.
